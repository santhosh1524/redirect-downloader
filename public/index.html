How it works:
  1. Loads the URL in a headless browser on the server.
  2. Locates the link or button matching your specified text (e.g. "Download Server 1").
  3. Clicks the button, waits for the configured delay, and repeats the click sequence.
  4. Streams the download file progress in real-time, preventing browser timeouts.
